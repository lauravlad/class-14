# Class 14

Predicate logic practice for PHIL 270, about 1 hour 15 minutes: identity, descriptions, and functions.

- Start here: definitions flashcards
- Part 1: Identity and counting (at least, exactly, at most; true in the basket?)
- Part 2: Except and only
- Part 3: Definite descriptions
- Part 4: Properties of relations
- Part 5: Functions and kinds of terms
- Test your knowledge: 10 questions at the end, with a score and review

After each answer, every choice shows what it means in plain English.

Every student gets the same exercises in the same order, so the class can work through them together. Progress is saved on each device.

Students need the class code from their teacher to enter.
